# Sources

This project was created for the [Hack the Video Agent Context Graph
hackathon](https://luma.com/hack-video-agent-context-graph-jul30-2026?tk=zCJzEX)
on July 30, 2026.

- [HackerSquad builder dashboard](https://hackersquad.io/builders/dashboard/events/cmrlol7wg000cmx0kl1lxj8xp/builder)
  — authenticated event workspace.

## Sponsor stack

The project is scored on its use of these four sponsor tools:

- [AWS](https://aws.amazon.com/) — cloud compute, storage, and databases.
- [OpenAI](https://openai.com/) — AI reasoning and deployment.
- [TwelveLabs](https://twelvelabs.io/) — multimodal, video-native AI.
- [Neo4j](https://neo4j.com/) — graph database for connected data.

The event dashboard also awards points for developer feedback with
`./give_developer_feedback.sh`.

## Submission

Submission follows three stages:

1. Save the project.
2. Record a video demo.
3. Submit to the judges.

The project can be saved repeatedly during the day. Judges only see it after
the final submission. Submit unlocks after the project has been saved and a
video demo has been recorded.

Required project details:

- Project name — pending.
- Project README/description — pending.
- Stack — AWS, OpenAI, TwelveLabs, and Neo4j.
- Other stack — add anything else used.
- Team roster — populated from the dashboard's Team tab.
- Git remote — <https://github.com/alee792/wake>.
- Consent to judging-partner email for submission or prize follow-up.

The dashboard's submission command is `./submit_project.sh`.
